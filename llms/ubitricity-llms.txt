# Ubitricity

> Ubitricity is a Berlin-based EV charging company (a wholly-owned Shell subsidiary) that integrates charge points into existing street infrastructure such as lampposts and bollards. It operates the UK's largest public on-street charging network, with networks in Germany and France. Its charging platform is built on the Open Charge Point Protocol (OCPP). Ubitricity does not currently publish a public developer API, developer portal, or machine-readable API specifications.

## Notes for agents

- There is no public Ubitricity API to call; driver charging is via the Pay-As-You-Go web experience and roaming networks.
- The charge point estate speaks OCPP to Ubitricity's backend (see their maintained Java-OCA-OCPP fork), but no OCPI/roaming or partner endpoint is publicly documented.
